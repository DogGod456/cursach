# Защитное ревью изменений

Адаптация методики Trail of Bits под лицензией CC BY-SA 4.0. [Источник и лицензия](../../SOURCES.md).

1. Сопоставить весь diff с исходной задачей. Найти изменённые операции и их потребителей по [методике](methodology.md).
2. Проверить сохранение проверок доступа и целостности по [памятке](patterns.md).
3. Проверить существующие тесты и ожидаемое поведение при отказе по [критериям](adversarial.md).
4. Оформить [заключение](reporting.md), пройти общий [цикл независимого ревью](../../review.md).
