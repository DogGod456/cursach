# Проверка изменений

Записать базовый и итоговый SHA. Для каждого изменённого публичного входа проследить проверку личности, разрешения, обращение к данным и обработку ошибки. Найти вызывающие функции, которым прежнее поведение могло быть важно. При изменениях схемы проверить совместимость с сохранёнными данными и фактические права роли приложения.
